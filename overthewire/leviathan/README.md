# Leviathan

Leviathan is the wargame OverTheWire points you to after Bandit. The jump is that it stops holding your hand: instead of a hint per level, you're dropped into a home directory with a file or a setuid binary and left to work out how it hands you the next password. It's the first real taste of poking at binaries and abusing privilege — `ltrace`, weird file permissions, and shell escapes.

Login is over SSH, same as Bandit, but on port **2223**:

    ssh leviathan0@leviathan.labs.overthewire.org -p 2223
