# OverTheWire

OverTheWire runs a set of security wargames: each one is a ladder of levels where you find a password, use it to log into the next level, and repeat. They're a good way to build the muscle memory that later challenges just assume you already have.

## Wargames

- [Bandit](bandit/README.md) *(Complete)* — Linux fundamentals: navigating the filesystem, permissions, basic scripting, enough command-line comfort to stop looking things up mid-challenge
- [Natas](natas/README.md) *(Complete)* — web security level by level: source code, cookies, headers, and eventually real vulnerabilities like SQLi, session attacks, and deserialization
- [Leviathan](leviathan/README.md) *(In Progress)* — binary and privilege basics: setuid programs, `ltrace`, odd file permissions, and shell escapes — the first step toward the harder OTW binary games
