# Become a Hacker

**Module:** Attacks and Defenses

## Key Points

- Ethical/offensive security ("white hat") means finding vulnerabilities with permission, so an organization can fix them before a real attacker exploits them — the same skills as an attacker, just different authorization and intent.
- A typical offensive engagement follows a rough methodology: **reconnaissance** (gather information) → **scanning/enumeration** (find live hosts, services, versions) → **exploitation** (turn a weakness into access) → **post-exploitation/privilege escalation** → **reporting**.
- Common offensive roles: penetration tester, red teamer, bug bounty hunter — they differ in scope, authorization, and how "quiet" the engagement needs to be.
- A signed scope / rules of engagement is what separates this work from actual crime — same techniques, explicit permission.

## Remember

Offensive security = same skills as an attacker, used with permission to find and report weaknesses before real attackers do. Methodology: recon → enumerate → exploit → escalate → report.
