# CIA Triad

**Module:** Attacks and Defenses

## Key Points

- The **CIA Triad** — Confidentiality, Integrity, Availability — is the core model for thinking about what security is protecting.
- **Confidentiality:** only authorized people/systems can access data (encryption, access controls, permissions).
- **Integrity:** data hasn't been tampered with or corrupted, whether in transit or at rest (checksums, hashing, digital signatures).
- **Availability:** systems and data are accessible to authorized users when needed (redundancy, backups, DDoS protection).
- A security control usually strengthens one or more of these three, and an attack usually targets one of them: a data breach hits confidentiality, ransomware hits availability, a MITM tampering with data in transit hits integrity.

## Remember

CIA = Confidentiality (who can see it), Integrity (has it been changed), Availability (can you get to it when you need it). Every attack and every defense maps back to one or more of these three.
