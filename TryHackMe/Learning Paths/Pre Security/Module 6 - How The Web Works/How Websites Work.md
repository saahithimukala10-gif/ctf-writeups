# How Websites Work

**Module:** How The Web Works

## Key Points

- A website is built from **front-end** (what the user sees/interacts with) and **back-end** (server-side logic and data) working together.
- Front-end building blocks:
  - **HTML** — structure/content of the page.
  - **CSS** — styling/layout.
  - **JavaScript** — interactivity, runs in the browser.
- Back-end handles things the client shouldn't/can't: business logic, databases, authentication — usually built with languages like Python, PHP, Node.js, Java, etc., and talks to a database (e.g. via SQL).
- **Static vs dynamic content:**
  - Static — same content served to everyone (plain HTML/CSS/images).
  - Dynamic — content generated per-request, often from a database (e.g. a profile page).
- The browser requests a page, the server (front-end + back-end together) builds/returns it, and the browser renders it.

## Remember

Front-end = HTML/CSS/JS in the browser. Back-end = server logic + database. Static = same for everyone; dynamic = generated per request.
